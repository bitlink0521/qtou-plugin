# 轻投：投后风险预警

先按 `qtou-connect` 技能连上轻投。业务操作只走 qtou MCP 工具，参数传 JSON 对象，返回 `isError` 时把 code 和 message 如实转告。默认只读，回写必须员工逐条确认。

## 执行清单

1. **取名单**：`agent_portfolio_list({ afterInvestOnly: true, pageSize: 50 })`（可加 `q` 过滤）。`hasMore: true` 就带 `page` 取下一页直到取完，企业数以 `total` 为准。记下每家的 projectId、项目名、公司全称、法人、成立日期、行业、投资日期。项目名相同但公司全称或法人不同的分开处理。
2. **取阈值**：`agent_risk_threshold_get()`，后面定级用它返回的值。
3. **季度财务**：每家调 `agent_portfolio_quarterly({ projectId })`（可带 `from` / `to`，格式 YYYYQn）。`finance` 每季两行：`type=current` 本期、`type=samePeriod` 去年同期。`reports` 是季报报送记录。返回「项目不存在或不属于当前租户」如实报，不换路径。
4. **舆情和公告**：每家都查，用公司全称加法人或成立日期消歧；主体对不上的结果不用，拿不准标「待核实」不定级。
   - 舆情：近 90 天，财经和主流媒体；同一事件 ≥2 家独立媒体才算确认。
   - 公告：近 12 个月，巨潮资讯、交易所、全国股转、国家企业信用信息公示系统、中国执行信息公开网、裁判文书网。
   - 检索区间一律写成「检索窗口：近N天（YYYY-MM-DD 至 运行日）」，如「舆情检索窗口：近90天（2026-08-04 至 2026-11-02）」。
   - 某个来源超时、报错、打不开，写「查询失败」及原因，**不得**写成「未发现」或「无风险」。
5. **定级**：读 [GRADING.md](GRADING.md)，每条写明命中哪一条、用了哪个阈值。
6. **出处（硬门槛）**：
   - 外网：标题 + 本轮亲自打开过的 URL + 发布日期 + ≤200 字逐字摘录。
   - 财务：每个出处一行，四栏分开：recordId（finance 行的 `id`）｜field（纯列名，如 `business_income`）｜季度（如 2026Q3）｜value（原值），另附本条用到的算式。
   - 一条假链接或摘录对不上，整份报告作废。禁止编造事件、链接、数字。
7. **出报告**：稿首标「AI 预警初判，需投后经理复核」；①总览：企业数、高 / 中 / 低条数、查询失败数；②按企业分节：基本信息 → 季度要点 → 预警列表（等级 / 类型 / 事件 / 日期 / 出处）→ 未发现项；③查询范围与失败清单。全部没信号就明说「未发现风险信号」并附查询范围。模拟数据醒目标注。
8. **员工确认后写入**：读 [WRITE.md](WRITE.md)。报告里列出全部拟写入条目；Codex 等支持表单的客户端对员工要写的条目逐条直接调 `agent_risk_alerts_create(confirmed: true)`，每条会弹确认卡让员工点「接受 / 拒绝」，返回 `USER_DECLINED` 就是不写、不重试；不支持表单的客户端逐条展示确认卡（项目名、等级、事件、出处），员工回复「确认写入」才调。

## 完成标准

- 名单翻完，每家都有财务、舆情、公告三部分结论（有结果 / 未发现 / 数据不足 / 查询失败四者之一）。
- 每条预警有命中条款和可核对出处；没有出处的不进报告。
- 员工确认的条目都已写入并用 `agent_risk_alerts_list` 读回核对；员工拒绝的什么都不调。

## 不做

不写无出处或链接打不开的条目；不把「查询失败」写成「无风险」；未经员工逐条确认不回写；季报逾期不拿 `update_date` 判。
