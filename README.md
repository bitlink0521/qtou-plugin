# 轻投（Cursor Plugin）

Skill + MCP + Logo，连轻投 Agent API。

## 复制这段发给 bot

```text
安装并连上轻投，做完再回报。

1. 优先团队市场 Import from Repo：https://github.com/bitlink0521/qtou-plugin
   若无：拷到 ~/.cursor/plugins/local/qtou-plugin，Reload Window。
2. 按 skill 弹表单收账密 → 代签 qtpat_ → 写入 QTOU_CONNECTOR_TOKEN。
3. 禁止手抄/粘贴 qtpat_…。
4. documents_search 或 portfolio_list 通即可；不要手填 MCP URL。
```

## 人工备用

- 团队市场 Import from Repo：同上 URL
- 或拷到 `~/.cursor/plugins/local/qtou-plugin` 后 Reload

## 包含

- Skill `skills/qtou` · MCP（连接器名「轻投」）· `assets/logo.svg`
- 变量 `QTOU_CONNECTOR_TOKEN`（Bearer `qtpat_…`）
